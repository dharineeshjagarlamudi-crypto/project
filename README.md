# FarmRescue 🌱
Act before the weather does.

## Features
- Farm overview dashboard
- 72-hour weather timeline
- Action board with priorities
- "Why?" reasoning cards
- What-If simulator

## Tech Stack
- Next.js + React
- Tailwind CSS
- Leaflet.js (map)
- Open-Meteo API (weather)
- Supabase (optional DB)
- Vercel (deployment)

## Run Locally
```bash
npx create-next-app farmrescue
cd farmrescue
npm install tailwindcss leaflet
npm run dev
